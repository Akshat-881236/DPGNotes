1. Architectural Scope & Software Requirements Specification (SRS)

Subsystem Directive: DMCA Copyright Arbitration, Automated Ephemeral Sweeping & Privacy Preservation.

The Software Requirements Specification (SRS Section 11.0) mandates strict adherence to international copyright safe harbor provisions. All uploaded study guides must allow copyright holders to submit digitally signed takedown requests. Upon verification, the target asset must be de-indexed immediately across the platform. Furthermore, to minimize legal liability and storage waste, ephemeral share links and temporary upload chunks are automatically scrubbed after 14 days.

Operational Invariant & Acceptance Criteria
All verified copyright takedown notices must trigger automated asset quarantines within 60 seconds of administrative confirmation. Ephemeral share links exceeding their 14-day lifecycle (expiresAt < now()) must be permanently purged by daily background cron workers without manual intervention.

2. Component Hierarchy & Compliance Workflow Topography

The legal compliance subsystem is organized into four core functional pillars:

  • 1. DMCA Notice & Arbitration Pipeline: A digital submission portal feeding a secured Firestore triage queue (dmca_reports). Allows institutional copyright agents to request prompt investigation and automated resource quarantining.
  • 2. 14-Day Ephemeral Data Sweeper (Cron Worker): A scheduled Node.js / Cloud Functions worker executing every 24 hours to sweep expired share links (share_links) and unlinked temporary Cloudinary assets.
  • 3. DRASA Academic Honor Governance: Enforces community guidelines prohibiting the publication of live exam answer keys, proprietary corporate training modules, or leaked confidential university documents.
  • 4. Privacy & Data Portability Engine (GDPR/CCPA): Provides self-service account deletion and data export endpoints (DELETE /api/users/me), stripping all personal identifiers and anonymizing reading logs.

3. Step-by-Step Production Implementation Guide

Follow the practical engineering roadmap to establish and maintain the DPGNotes Legal Compliance subsystem:

  1. Deploy Centralized Legal Hub: Maintain official legal documents at designated URLs (/legal/dmca-policy.html, /legal/privacy-policy.html, /legal/drasa-policy.html) linked to from all module footers.
  2. Configure Scheduled Ephemeral Sweeper: Write a Node.js cron routine (using node-cron or Firebase Cloud Functions) executing daily at 02:00 UTC to query and purge expired tokens.
  3. Implement Anonymized Telemetry Scrubbing: Hash client IP addresses using SHA-256 with a daily rotating salt before storing telemetry logs in Firestore to protect student privacy.
  4. Build Single-Click Quarantine Controller: Provide administrators with an authenticated dashboard toggle that instantly updates a document's status to quarantined, removing it from public search feeds.
  5. Ensure E-E-A-T Search Quality Guidelines: Include clear authorship, institutional affiliations, and publication dates in page metadata to maximize Google E-E-A-T quality ratings.

// Module 11: 14-Day Ephemeral Data Sweeper & Privacy Anonymizer
const admin = require('firebase-admin');
const db = admin.firestore();

/**
 * Sweeps expired share tokens and ephemeral resources older than 14 days
 */
async function sweepEphemeralRecords() {
  const now = admin.firestore.Timestamp.now();
  console.log('[SWEEPER] Starting 14-day ephemeral cleanup cycle at', now.toDate().toISOString());

  try {
    // 1. Query expired share links
    const snapshot = await db.collection('share_links')
      .where('expiresAt', '<=', now)
      .limit(500)
      .get();

    if (snapshot.empty) {
      console.log('[SWEEPER] Zero expired share links found.');
      return { purgedCount: 0 };
    }

    const batch = db.batch();
    snapshot.docs.forEach((doc) => {
      batch.delete(doc.ref);
    });

    await batch.commit();
    console.log(`[SWEEPER] Successfully purged ${snapshot.size} expired share links.`);
    return { purgedCount: snapshot.size };
  } catch (err) {
    console.error('[SWEEPER-ERROR] Cleanup failed:', err.message);
    throw err;
  }
}

/**
 * GDPR Right-to-be-Forgotten: Purges personal data and anonymizes audit logs
 */
async function purgeUserData(uid) {
  const userRef = db.collection('users').doc(uid);
  const userSnap = await userRef.get();
  if (!userSnap.exists) return { success: false, message: 'User not found' };

  await db.runTransaction(async (transaction) => {
    // Anonymize user record
    transaction.update(userRef, {
      displayName: 'Former Student',
      email: 'deleted@anonymized.dpgnotes.org',
      photoURL: null,
      role: 'guest',
      isAnonymized: true,
      anonymizedAt: admin.firestore.FieldValue.serverTimestamp()
    });
  });

  console.log(`[GDPR-COMPLIANCE] User ${uid} successfully anonymized.`);
  return { success: true };
}

module.exports = { sweepEphemeralRecords, purgeUserData };
