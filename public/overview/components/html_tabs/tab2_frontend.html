Frontend Engineering & UI Component Hierarchy

16 min read Production-Verified DRASA Engineering Standard

Frontend engineering in DPGNotes prioritizes raw runtime efficiency, zero-framework overhead, and universal device responsiveness. By utilizing Vanilla JavaScript (ES6+), semantic HTML5, and CSS3 custom properties, the platform delivers instantaneous First Contentful Paint (FCP) and continuous 60fps rendering across devices ranging from compact 280px foldable phones to multi-monitor 4K desktop environments.

Core Tech: HTML5 Canvas CSS3 Custom Properties Vanilla JavaScript ES6+ Responsive Breakpoints DOM Event Delegation CSS Grid & Flexbox Web Storage API IntersectionObserver

1. Architectural Scope & Software Requirements Specification (SRS)

Subsystem Directive: Zero-Framework Vanilla JS Component Architecture, CSS Custom Properties & Responsive Breakpoints.

The Software Requirements Specification (SRS Section 2.0) requires client bundle weights to remain strictly under 250KB uncompressed, eliminating high-overhead frameworks like React or Angular. Interface rendering must maintain complete cross-browser parity on Chromium, WebKit, and Gecko engines while offering complete dark/light auto-theming, keyboard accessibility (WAI-ARIA), and zero layout shifts (CLS < 0.05).

Operational Invariant & Acceptance Criteria
All UI state mutations must occur directly in the DOM tree or through native CustomEvents, preserving a predictable unidirectional event-loop without virtual-DOM reconciliation overhead.

2. Component Hierarchy & Core Data Flows

The client application is organized into modular Vanilla JS units with decoupled lifecycles:

  • 1. Theme & Token Engine (CSS3): Over 40 CSS custom properties defining color palettes, border radii, typography, elevation shadows, and transition velocities.
  • 2. SPA Router & Dynamic Tab Switcher: Hash-based and programmatic navigation that unmounts stale modules, invalidates event listeners, and mounts active modules in sub-10ms intervals.
  • 3. Canvas DRM Watermarking Engine: Dynamic HTML5 canvas layer overlaying contributor attribution and tamper-proof user timestamps on academic assets.
  • 4. Shared Dialog & Modal Subsystem: Universal alert, confirm, and prompt replacements (custom-dialogs.js) providing modal control across mobile and desktop.

3. Step-by-Step Production Implementation Guide

Follow the practical engineering roadmap to configure, implement, and deploy this subsystem:

  1. Define root CSS variables in style.css mapping semantic color tokens (--bg-primary, --text-primary, --accent-glow) across theme-dark, theme-light, and theme-auto modes.
  2. Construct lightweight JavaScript module classes exposing mount(container), render(), and unmount() lifecycle hooks.
  3. Attach top-level event delegation listeners to document.body to intercept clicks on dynamic cards, preventing memory leaks from orphan event handlers.
  4. Integrate IntersectionObserver for lazy-loading heavy media elements, off-screen images, and native advertisement banners.
  5. Implement media-query breakpoints for 5 responsive tiers: Foldable (280px–360px), Mobile (361px–480px), Tablet (481px–768px), Laptop (769px–1200px), and Desktop (>1200px).

// Module 2: Vanilla JS Dynamic Component Router & Watermark Engine
class DPGComponentRouter {
  constructor(containerId) {
    this.container = document.getElementById(containerId);
    this.activeComponent = null;
    this.cache = new Map();
  }

  async loadComponent(componentName, renderFn) {
    if (this.activeComponent && typeof this.activeComponent.destroy === 'function') {
      this.activeComponent.destroy();
    }

    this.container.classList.add('transition-fade-out');
    await new Promise(r => setTimeout(r, 120));

    let html = this.cache.get(componentName);
    if (!html) {
      html = await renderFn();
      this.cache.set(componentName, html);
    }

    this.container.innerHTML = html;
    this.container.classList.remove('transition-fade-out');
    this.container.classList.add('transition-fade-in');

    this.renderWatermark();
  }

  renderWatermark() {
    const canvas = document.createElement('canvas');
    canvas.width = 300;
    canvas.height = 150;
    const ctx = canvas.getContext('2d');
    ctx.rotate(-20 * Math.PI / 180);
    ctx.font = '14px Inter, sans-serif';
    ctx.fillStyle = 'rgba(255, 255, 255, 0.04)';
    ctx.fillText('DPGNotes Academic Platform', 20, 80);
    this.container.style.backgroundImage = `url(\${canvas.toDataURL()})`;
  }
}

window.dpgRouter = new DPGComponentRouter('mainContentCanvas');
