Educational Media Studio & Video Ecosystem

16 min read Production-Verified DRASA Engineering Standard

Visual learning requires low-latency playback, resilient offline checkpointing, and dynamic monetization without user disruption. The DPGNotes Educational Media Studio deploys a dual-mode video architecture: an ultra-responsive native HTML5 video player for locally hosted lecture records and an integrated YouTube IFrame API bridge for curated external university courses. To safeguard playback progress under flaky campus Wi-Fi, the player implements a double-write persistence pattern across LocalStorage and Cloud Firestore.

1. Architectural Scope & Software Requirements Specification (SRS)

Subsystem Directive: Dual Video Rendering Engines, Resilient Playback Checkpointing & Native Sponsor Swapping.

The Software Requirements Specification (SRS Section 9.0) mandates seamless playback across desktop workstations, mobile phones, and foldable devices. The video subsystem must handle unstable network connections without resetting lecture timestamps, support instant sharing via 8-character token links (/video.html?v=<token>), and provide contextual academic advertising while adhering to strict privacy protections.

Operational Invariant & Acceptance Criteria
Every lecture viewing session must save playback timestamps every 5 seconds. If network connectivity drops or the student accidentally reloads the browser, the player must immediately resume playback from the exact second recorded in the double-write persistence layer without buffering delays.

2. Component Hierarchy & Dual-Engine Playback Architecture

The video subsystem coordinates five key components to ensure uninterrupted educational media delivery:

  • 1. Adaptive Player Controller (Vanilla JS): Auto-detects media source URLs. If an MP4/WebM URL is supplied, it initializes the custom HTML5 video player; if a YouTube video ID or URL is supplied, it initializes the YouTube IFrame player with custom controls.
  • 2. Double-Write Persistence Layer: Writes playback timestamps concurrently to browser LocalStorage (synchronous, instant) and Cloud Firestore (asynchronous, debounced at 5 seconds) to eliminate data loss.
  • 3. Contextual Sponsor Interstitial Engine: Injects non-intrusive academic sponsorships and DRASA partner announcements into pre-roll and mid-roll slots based on course category.
  • 4. Ephemeral Share Link Resolver: Parses ?v=<token> query parameters via redirect.js and expands short tokens to authentic lecture IDs with atomic view incrementation.
  • 5. Fluid Responsive Frame (CSS3): Enforces modern aspect-ratio: 16 / 9 rules with dark letterboxing, glassmorphic scrubber bars, and mobile touch gestures (double-tap to seek 10 seconds).

3. Step-by-Step Production Implementation Guide

Follow the practical engineering roadmap to build and deploy the DPGNotes Video Studio:

  1. Construct HTML5 Container: Set up a responsive wrapper with aspect-ratio: 16 / 9; max-width: 100%; position: relative; preventing layout shifts on initial paint.
  2. Implement Video Source Detection: Parse incoming strings with regular expressions identifying standard YouTube URL patterns (e.g., youtu.be/, watch?v=) versus direct video file extensions (.mp4, .webm).
  3. Bind TimeUpdate Listeners: Listen for timeupdate on native video or getCurrentTime() intervals on YouTube to write the timestamp to localStorage.setItem(`dpg_video_pos_${id}`, currentTime).
  4. Debounce Firestore Synchronization: Dispatch an asynchronous Firestore update every 5 seconds to persist progress across devices for authenticated students.
  5. Attach Keyboard Accessibility Shortcuts: Bind document keydown events: Spacebar to toggle Play/Pause, Left Arrow to rewind 5 seconds, Right Arrow to advance 5 seconds, and 'F' key to toggle fullscreen.

// Module 9: Dual Video Engine & Double-Write Persistence Controller
class DPGVideoPlayer {
  constructor(containerId, options = {}) {
    this.container = document.getElementById(containerId);
    this.videoId = options.videoId;
    this.videoUrl = options.videoUrl;
    this.playerType = this.detectType(this.videoUrl);
    this.lastSavedSec = 0;
  }

  detectType(url) {
    if (!url) return 'html5';
    if (url.includes('youtube.com') || url.includes('youtu.be')) return 'youtube';
    return 'html5';
  }

  getSavedPosition() {
    const local = localStorage.getItem(`dpg_pos_${this.videoId}`);
    return local ? parseFloat(local) : 0;
  }

  savePosition(seconds) {
    if (Math.abs(seconds - this.lastSavedSec) < 2) return;
    this.lastSavedSec = seconds;

    // 1. Instant local persistence
    localStorage.setItem(`dpg_pos_${this.videoId}`, seconds.toString());

    // 2. Debounced asynchronous cloud persistence
    if (window.firebase && window.currentAuthUser) {
      window.firebase.firestore().collection('video_progress').doc(`${window.currentAuthUser.uid}_${this.videoId}`).set({
        positionSec: seconds,
        updatedAt: window.firebase.firestore.FieldValue.serverTimestamp()
      }, { merge: true }).catch(() => {});
    }
  }

  render() {
    this.container.innerHTML = '';
    const initialPos = this.getSavedPosition();

    if (this.playerType === 'html5') {
      const videoEl = document.createElement('video');
      videoEl.className = 'dpg-native-video';
      videoEl.src = this.videoUrl;
      videoEl.controls = true;
      videoEl.playsInline = true;

      videoEl.addEventListener('loadedmetadata', () => {
        if (initialPos > 0) videoEl.currentTime = initialPos;
      });

      videoEl.addEventListener('timeupdate', () => {
        this.savePosition(videoEl.currentTime);
      });

      this.container.appendChild(videoEl);
    } else {
      // YouTube IFrame Integration
      const ytId = this.extractYouTubeId(this.videoUrl);
      const iframe = document.createElement('iframe');
      iframe.className = 'dpg-youtube-iframe';
      iframe.src = `https://www.youtube-nocookie.com/embed/${ytId}?start=${Math.floor(initialPos)}&enablejsapi=1`;
      iframe.allow = 'accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture';
      iframe.allowFullscreen = true;
      this.container.appendChild(iframe);
    }
  }

  extractYouTubeId(url) {
    const regExp = /^.*(youtu.be\/|v\/|u\/\w\/|embed\/|watch\?v=|\&v=)([^#\&\?]*).*/;
    const match = url.match(regExp);
    return (match && match[2].length === 11) ? match[2] : '';
  }
}

window.DPGVideoPlayer = DPGVideoPlayer;
