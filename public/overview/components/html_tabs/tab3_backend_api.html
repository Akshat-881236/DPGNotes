1. Architectural Scope & Software Requirements Specification (SRS)

Subsystem Directive: High-Throughput Node.js Microservices, Dual Token Validation & Resilient REST Pipelines.

The Software Requirements Specification (SRS Section 3.0) mandates a stateless, horizontally scalable API tier capable of processing thousands of concurrent student queries during peak university exam cycles without thread-locking. The backend acts as the authoritative security gateway between untrusted public client browsers, Google Cloud Firestore multi-region clusters, Cloudinary media storage, and Python-powered PDF analytics workers.

Operational Invariant & Acceptance Criteria
All incoming requests to state-mutating endpoints (/api/documents, /api/share/*, /api/auth/*) must pass three consecutive validation gates: (1) IP-based rate limiting, (2) strict CORS origin verification, and (3) cryptographic RS256 Firebase Admin session token validation. Requests failing any gate are terminated immediately with standard HTTP 401/403/429 status codes before executing database reads or memory-intensive tasks.

2. Component Hierarchy, Multi-Tier Connectivity & Microservices Flow

The backend architecture decouples concerns across five specialized middleware and routing modules:

  • 1. Security & Reverse Proxy Trust Middleware: Configures app.set('trust proxy', 1) to inspect real client IPs via X-Forwarded-For headers behind Firebase Hosting edge CDNs. Enforces Helmet security headers, removes X-Powered-By, and whitelists only trusted origin domains (https://dpgnotes.web.app).
  • 2. Authentication & RBAC Gate (Firebase Admin SDK): Intercepts Authorization: Bearer <token> headers, decodes claims against Firebase Public Keys, checks contributor verification status, and attaches authenticated user profiles to req.user.
  • 3. RESTful Resource Dispatchers: Modular Express router instances handling academic document queries, study material submissions, short-token URL resolution, and search indexing across all 8 academic categories.
  • 4. Python Microservice Inter-Process Bridge: Node.js proxies complex document parsing and OCR extraction requests to an internal Python FastAPI worker via secured HTTP/2 channels, keeping the Node.js event loop completely non-blocking.
  • 5. Resilient Transactional Mailer (Brevo SMTP): Dispatches critical security notices (2FA codes, account approvals, and password reset confirmations) with automated timeout fallbacks, suppressing non-essential marketing emails.

3. Step-by-Step Production Implementation Guide

Follow the practical engineering roadmap to configure, implement, and deploy the DPGNotes Node.js backend subsystem:

  1. Initialize Project & Dependencies: Set up a Node.js 20 LTS project with express, cors, helmet, express-rate-limit, firebase-admin, and dotenv.
  2. Configure Reverse Proxy & Security Boundary: Configure Express with app.set('trust proxy', 1) to ensure accurate IP identification behind Firebase Hosting CDN rewrites, followed by strict CORS origin validation.
  3. Implement Sliding-Window Rate Limiters: Attach express-rate-limit instances restricting public search and read endpoints to 300 requests per 15 minutes, while tightening mutating upload routes to 20 requests per hour per IP.
  4. Construct Auth Middleware Guard: Write a custom Express middleware extracting bearer tokens and verifying cryptographic signatures with admin.auth().verifyIdToken().
  5. Bridge to Python Worker: Implement an asynchronous proxy controller using native fetch with an AbortController timeout (10 seconds) to delegate PDF cover extraction and text parsing to the Python microservice.
  6. Deploy Uptime & Health Probes: Expose a lightweight /api/health endpoint returning memory statistics and process uptime for automated micro-daemon keep-alive pings.

// Module 3: Production Express Gateway, Auth Guard & Python Worker Bridge
const express = require('express');
const helmet = require('helmet');
const cors = require('cors');
const rateLimit = require('express-rate-limit');
const admin = require('firebase-admin');

// 1. Initialize Firebase Admin SDK
if (!admin.apps.length) {
  admin.initializeApp({
    credential: admin.credential.applicationDefault()
  });
}

const app = express();
app.set('trust proxy', 1); // Crucial for Firebase Hosting & Cloudflare reverse proxy
app.use(helmet({ contentSecurityPolicy: false }));
app.use(express.json({ limit: '10mb' }));

// 2. Strict CORS Security Whitelist
const ALLOWED_ORIGINS = ['https://dpgnotes.web.app', 'https://dpgnotes.firebaseapp.com'];
app.use(cors({
  origin: (origin, callback) => {
    if (!origin || ALLOWED_ORIGINS.includes(origin)) {
      return callback(null, true);
    }
    return callback(new Error('Cross-Origin Request Blocked by DRASA Security Policy'));
  },
  credentials: true
}));

// 3. Sliding-Window Rate Limiting
const globalApiLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 minutes
  max: 300,
  standardHeaders: true,
  legacyHeaders: false,
  message: { error: 'Too many requests. Please slow down and retry in 15 minutes.' }
});
app.use('/api/', globalApiLimiter);

// 4. Cryptographic Authentication & Contributor RBAC Guard
async function authenticateContributor(req, res, next) {
  const authHeader = req.headers.authorization;
  if (!authHeader || !authHeader.startsWith('Bearer ')) {
    return res.status(401).json({ error: 'Unauthorized: Missing or malformed authorization header.' });
  }

  const token = authHeader.split('Bearer ')[1];
  try {
    const decodedToken = await admin.auth().verifyIdToken(token);
    req.user = decodedToken;
    next();
  } catch (err) {
    return res.status(401).json({ error: 'Session expired or invalid cryptographic token: ' + err.message });
  }
}

// 5. Python Microservice Delegation Bridge
app.post('/api/documents/process-pdf', authenticateContributor, async (req, res) => {
  const { pdfUrl, documentId } = req.body;
  if (!pdfUrl || !documentId) {
    return res.status(400).json({ error: 'Parameters pdfUrl and documentId are required.' });
  }

  try {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 12000);

    const pyWorkerUrl = process.env.PYTHON_WORKER_URL || 'http://127.0.0.1:8000';
    const pyResponse = await fetch(`${pyWorkerUrl}/api/py/extract-metadata`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-Internal-Secret': process.env.INTERNAL_BRIDGE_SECRET || 'dpg-vault-secret'
      },
      body: JSON.stringify({ pdfUrl, documentId }),
      signal: controller.signal
    });
    clearTimeout(timeout);

    if (!pyResponse.ok) {
      throw new Error(`Python worker returned status ${pyResponse.status}`);
    }

    const result = await pyResponse.json();
    return res.status(200).json({ success: true, metadata: result });
  } catch (err) {
    console.error('[BRIDGE-ERROR] Python worker delegation failed:', err.message);
    return res.status(502).json({ error: 'Media extraction worker temporarily unavailable.' });
  }
});

// 6. High-Availability Health Probe
app.get('/api/health', (req, res) => {
  res.status(200).json({
    status: 'ONLINE',
    uptimeSeconds: Math.floor(process.uptime()),
    memoryUsageMB: Math.round(process.memoryUsage().rss / 1024 / 1024),
    timestamp: new Date().toISOString()
  });
});

const PORT = process.env.PORT || 5000;
app.listen(PORT, () => {
  console.log(`[DPG-BACKEND] Node.js cluster active on port ${PORT}`);
});
