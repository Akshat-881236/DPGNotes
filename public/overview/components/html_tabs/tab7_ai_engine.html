Multi-Engine AI Orchestration & Fallback Pipelines

18 min read Production-Verified DRASA Engineering Standard

Academic intelligence at scale demands continuous availability and zero single-vendor dependency. DPGNotes implements a resilient multi-model AI pipeline: incoming student prompts, assignment generation requests, and study queries route first through Google Gemini 1.5/2.0 Pro and Flash models for deep pedagogical synthesis. If upstream rate limits (HTTP 429), regional outages, or quota spikes occur, an automated circuit breaker switches transparently to xAI Grok with zero dropped requests.

Operational Invariant & Acceptance Criteria
The AI orchestrator must implement an automated 3-tier cascade: (1) Gemini 1.5/2.0 Flash for sub-second responses, (2) Gemini 1.5 Pro for deep mathematical problem-solving, and (3) xAI Grok as an immediate failover gateway. Switching between providers must occur in under 500ms without user-visible error dialogs.

2. Component Hierarchy & AI Failover Topography

The AI orchestration subsystem bridges client interfaces with multi-cloud intelligence clusters:

  • 1. Vanilla JS Streaming Client: Utilizes native fetch with readable stream readers (response.body.getReader()) and TextDecoder to paint tokens onto the screen in real-time typewriter sequence. Supports user cancellation via AbortController.
  • 2. Node.js AI Orchestration Router: Manages API request lifecycles, injects verified university syllabus context, and tracks failure rates per vendor using an in-memory circuit breaker.
  • 3. Google Gemini Engine (Primary): Dispatches structured prompts to gemini-1.5-flash and gemini-1.5-pro using Google GenAI REST APIs with system instructions enforcing academic accuracy and step-by-step reasoning.
  • 4. xAI Grok Engine (Automated Fallback): Standby endpoint powered by Grok REST interfaces, instantly activated when Gemini endpoints return HTTP 429, 500, or 503 errors.
  • 5. Python Token Chunking Worker: Pre-processes lengthy multi-page assignment PDFs, tokenizing text into semantically coherent 2,000-token chunks to prevent context-window overflow.

3. Step-by-Step Production Implementation Guide

Follow the practical engineering roadmap to build and deploy the DPGNotes AI Orchestration engine:

  1. Configure API Environment Keys: Securely inject GEMINI_API_KEY and XAI_GROK_API_KEY from the Cryptographic Security Vault.
  2. Design System Prompts with Pedagogical Constraints: Craft system prompts constraining the AI to official university curricula, mandating step-by-step proofs, and requiring LaTeX notation (\( ... \) for inline, \[ ... \] for block math).
  3. Build Node.js Circuit Breaker: Maintain a failure counter. If 3 consecutive requests to the primary provider fail or timeout within 8 seconds, trip the breaker to route directly to the fallback engine for 60 seconds.
  4. Implement Streaming Output Handlers: Pipe the upstream chunked stream directly into Express res with headers Content-Type: text/event-stream and Cache-Control: no-cache.
  5. Client-Side Markdown & Math Hydration: Use a lightweight client markdown parser coupled with KaTeX auto-render to transform incoming text tokens into interactive equations without UI freezing.

// Module 7: Node.js Multi-Engine AI Orchestrator with Grok Fallback
const express = require('express');
const router = express.Router();

let isGeminiHealthy = true;
let geminiFailureCount = 0;
const MAX_FAILURES = 3;

async function callGeminiStream(prompt, res) {
  const apiKey = process.env.GEMINI_API_KEY;
  const endpoint = `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:streamGenerateContent?key=${apiKey}`;

  const response = await fetch(endpoint, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      contents: [{ role: 'user', parts: [{ text: prompt }] }],
      systemInstruction: { parts: [{ text: 'You are DPGNotes Academic AI Tutor. Provide step-by-step verified explanations using LaTeX math formatting.' }] }
    })
  });

  if (!response.ok) throw new Error(`Gemini HTTP Error ${response.status}`);
  return response.body;
}

async function callGrokStream(prompt, res) {
  const apiKey = process.env.XAI_GROK_API_KEY;
  const endpoint = 'https://api.x.ai/v1/chat/completions';

  const response = await fetch(endpoint, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${apiKey}`
    },
    body: JSON.stringify({
      model: 'grok-beta',
      messages: [
        { role: 'system', content: 'You are DPGNotes Academic AI Tutor. Provide step-by-step verified academic solutions.' },
        { role: 'user', content: prompt }
      ],
      stream: true
    })
  });

  if (!response.ok) throw new Error(`xAI Grok HTTP Error ${response.status}`);
  return response.body;
}

router.post('/api/ai/query', async (req, res) => {
  const { prompt } = req.body;
  if (!prompt) return res.status(400).json({ error: 'Prompt is required.' });

  res.setHeader('Content-Type', 'text/plain; charset=utf-8');
  res.setHeader('Transfer-Encoding', 'chunked');

  try {
    let stream;
    if (isGeminiHealthy) {
      try {
        stream = await callGeminiStream(prompt, res);
        geminiFailureCount = 0;
      } catch (geminiError) {
        console.warn('[AI-FAILOVER] Gemini failed, tripping circuit breaker:', geminiError.message);
        geminiFailureCount++;
        if (geminiFailureCount >= MAX_FAILURES) isGeminiHealthy = false;
        // Immediate seamless fallback to Grok
        stream = await callGrokStream(prompt, res);
      }
    } else {
      console.log('[AI-ROUTER] Routing directly to xAI Grok fallback.');
      stream = await callGrokStream(prompt, res);
    }

    const reader = stream.getReader();
    const decoder = new TextDecoder();
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      res.write(decoder.decode(value, { stream: true }));
    }
    res.end();
  } catch (fatalError) {
    console.error('[AI-FATAL]', fatalError.message);
    if (!res.headersSent) res.status(503).json({ error: 'All AI engine providers temporarily busy.' });
    else res.end('\n[SYSTEM: Transmission interrupted due to upstream network error.]');
  }
});

module.exports = router;
