Website Verification & Analytics Integration

Complete the compulsory meta tag verification below to enable DPGNotes SERP inclusion. Verification must be completed within 48 hours, otherwise the site entry will be automatically purged.

1️⃣ Compulsory Meta Tag Verification (SERP Inclusion)

Add the following meta tag to the <head> section of your website source code:

<meta name="dpg-notes-verification-tag" content="FIREBASE_DOC_ID">

2️⃣ DPGNotes Analytics Script Integration (Optional Advanced Telemetry)

To enable detailed visitor screentime, outbound link audit, geolocation tracking, and phishing threat protection on DPGNotes, add this script tag to your site's <head>:

<script src="https://dpgnotes.web.app/track-init.js?referer-to=FIREBASE_DOC_ID&used-by=CONTRIBUTOR_UID" defer></script>
