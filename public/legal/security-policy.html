DPGNotes Security & Infrastructure Policy

Effective Date: July 13, 2026 | Document ID: POL-DPG-SEC-2026-V3

1. Security Architecture Overview

DPGNotes employs a defense-in-depth model safeguarding all cloud database nodes, REST endpoints, and client-side web applications against contemporary cyber threats.

2. Multi-Layer Protection Measures

  • Server-Side Firestore Security Rules: Direct database writes are governed by atomic validation rules, strictly restricting document edits to verified authors and administrators.
  • Cryptographic Data Protection: All database storage is encrypted at rest using AES-256; data in transit is encrypted using TLS 1.3.
  • JWT Token Authorization: Administrative endpoints and analytical writes require cryptographically signed JSON Web Tokens.
  • Content Security & Sanitization: Client-rendered Markdown and HTML content undergo strict sanitization via DOMPurify to neutralize cross-site scripting (XSS) vectors.

3. Responsible Vulnerability Disclosure

Security researchers who discover potential vulnerabilities are invited to report them confidentially to our engineering team via our Support & Grievance Portal. We commit to acknowledging reports within 48 hours.
