Computer Science & Software Engineering Core Modules

The DPGNotes Computer Science repository covers core theoretical and practical subjects required for modern software engineering and computer application degrees (BCA, B.Tech, M.Tech, and MCA).

  • Computer Organization & Architecture (COA): Instruction set architectures, CPU registers, pipelining, cache memory mapping, memory management units, and digital logic circuits.
  • Database Management Systems (DBMS): Relational database design, E-R modeling, SQL queries, normalization (1NF, 2NF, 3NF, BCNF), and ACID transaction properties.
  • Object-Oriented Java Programming: Classes, inheritance, polymorphism, interface contracts, exception handling, multithreading, and AWT/Swing GUI components.
  • Operating Systems (OS): Process scheduling algorithms (FCFS, SJF, Round Robin), deadlocks, virtual memory management, paging, and file systems.

Our notes are accompanied by verified previous year examination question papers (PYQs) and sessional solutions to help students prepare effectively for term exams.

Health Education, First Aid & Physical Education Notes

  • Health Education & Hygiene: Principles of personal health, nutrition, wellness, and preventive hygiene.
